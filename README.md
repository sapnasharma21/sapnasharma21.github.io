# Task 5: Static Website Deployment on GitHub Pages

## What I Did
- Created a public repo named `sapnasharma21.github.io`
- Built a simple static portfolio website using HTML, CSS, and JavaScript
- Pushed the code to GitHub
- Enabled GitHub Pages (branch: main, folder: root)
- Hosted the site live at: https://sapnasharma21.github.io

## Files
- `index.html` – main webpage structure
- `style.css` – styling with custom colors, gradients, and a responsive project grid
- `script.js` – simple button interaction

## What I Learned
- How Git version control works (clone, add, commit, push)
- How to deploy a static site for free using GitHub Pages
- Difference between static and dynamic hosting
